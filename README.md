# Customer Report | SQL Data Analytics Project

## Project Overview
This project focuses on analyzing customer data using SQL to generate a comprehensive customer report. The report consolidates key customer metrics and behavioral insights to better understand customer characteristics, purchasing patterns, and customer segments.

The project uses SQL queries to combine customer information with transaction data, calculate important KPIs, and categorize customers based on their purchasing behavior and age groups.

## Project Objectives
- **Consolidate Customer Information:** Gather essential customer details, including names, age, and transaction-related information.
- **Segment Customers:** Categorize customers into VIP, Regular, and New customer segments based on their purchasing behavior.
- **Group Customers by Age:** Classify customers into different age groups to understand customer demographics.
- **Calculate Key Performance Indicators (KPIs):** Generate valuable customer metrics to analyze purchasing patterns and customer value.
- **Generate a Customer Report:** Combine customer-level metrics into a structured report for easier analysis and interpretation.

## Tools and Technologies
- SQL Server
- SQL Server Management Studio (SSMS)
- SQL for data extraction, transformation, and analysis

## Key Analysis and Features
- Customer-level data aggregation
- Customer age calculation and age-group classification
- Customer segmentation into VIP, Regular, and New categories
- Calculation of customer KPIs, including recency, average order value, and average monthly spend
- Analysis of customer transaction history
- Use of Common Table Expressions (CTEs) to organize complex queries
- Data transformation and report generation using SQL

## Key Learnings
- Writing SQL queries to analyze customer and transaction data
- Using aggregate functions to calculate customer metrics
- Applying conditional logic to categorize customers
- Using CTEs to structure multi-step analytical queries
- Transforming raw data into meaningful customer insights
